# Publication Boundaries

Use this reference when preparing the skill for public release or when adapting the Words Over Time method for another project.

## What This Skill Shares

This skill shares a design method:

- Build an evidence contract before designing visuals.
- Use grid structure as an argument.
- Keep source type, transform, caveat, and rights visible.
- Treat color, type, spacing, and interaction as programmable rules.
- Review the artifact for claim integrity before visual polish.

These methods can be applied to many subjects: archives, word histories, public policy, research reports, data journalism, museum interpretation, scientific explainers, and editorial dashboards.

## What It Does Not Automatically Share

This skill does not automatically grant reuse of:

- The complete Words Over Time website design as a copied visual identity.
- Dai Pan / 潘岱 authorship marks or project branding.
- Curated Words Over Time datasets, classifications, annotations, page compositions, or research writing.
- Third-party source material cited by Words Over Time.
- Any upstream corpus, dictionary, archive, legal, policy, clinical, or publisher material.

When adapting, copy the reasoning pattern, not the finished identity.

## License Decision

Choose a license before publishing this skill as a standalone public package.

Practical options:

- MIT: familiar for software repositories and permissive reuse.
- Apache-2.0: permissive reuse with explicit patent language.
- CC BY 4.0: appropriate for documentation, writing, and design-method text when attribution matters.
- CC BY-NC 4.0: restricts commercial use, but is not considered open source by common open-source definitions.

If the goal is broad open-source sharing with attribution, CC BY 4.0 is a good default for the written skill materials. If the goal is compatibility with code repositories, MIT is simpler. Keep project-specific Words Over Time content and third-party source material outside the license grant unless the author explicitly chooses otherwise.

## Public Release Checklist

Before sharing:

- Run the skill validator.
- Remove private notes, unfinished placeholders, and local-only assumptions.
- Confirm that examples do not include restricted text, unreleased data, or copied visual assets.
- Add a license file once the author chooses the license.
- Mention that the skill generalizes a method and should not be used to clone Words Over Time's identity.
- Test at least one prompt from `prompt-recipes.md`.
